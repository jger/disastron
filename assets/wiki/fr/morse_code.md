## Temps
- **Point (dit)** — court.
- **Trait (dah)** — ~3× point.
- **Écart intra-lettre** — ~1 point.
- **Écart entre lettres** — ~3 points.
- **Écart entre mots** — ~7 points.

Pratiquer lentement ; lisible bat rapide.

## Détresse : SOS
**S** `...` — **O** `---` — **S** `...` (espacement normal entre ces trois lettres).

Utilisez l’outil **SOS** du tableau de bord pour lampe/écran/audio/vibration synchronisés.
