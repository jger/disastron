## Timing
- **Dot (dit)** — short mark.
- **Dash (dah)** — ~3× dot length.
- **Gap within a letter** — ~1 dot.
- **Gap between letters** — ~3 dots.
- **Gap between words** — ~7 dots.

Practice slowly; readable beats fast.

## Distress: SOS
**S** `...` — **O** `---` — **S** `...` (normal spacing between those three letters).

Use the Dashboard **SOS** tool for synced torch/screen/audio/vibration Morse when signaling.
